Student Productivity Hub is an intuitive web application designed to help students streamline their daily tasks, manage time effectively, and boost productivity.

It combines essential tools like a Pomodoro timer, notes manager, and task tracker into one unified platform.

✨ Features
⏱️ Pomodoro Timer
Helps you stay focused using the Pomodoro technique (25-minute work sessions + breaks).
📝 Notes Management
Create, edit, and delete notes easily in one place.
✅ Task Manager (To-Do List)
Organize daily tasks and track completion.
🎨 Modern UI Design
Clean, responsive, and visually appealing interface for better user experience.
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Design: Responsive UI with modern styling
Storage (Optional): LocalStorage (for saving notes/tasks)
